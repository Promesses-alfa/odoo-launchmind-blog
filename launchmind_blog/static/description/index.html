What's included

Explicit destination

Select an existing website/blog pair in Settings > Website, enter your API key server-side, and click Connect. Signed installation confirmation must complete before delivery. The destination locks once owned posts exist.

Retryable delivery

Launchmind delivers through a signed webhook with retained retry state. Odoo scheduled work handles optional discovery, notifications and daily health. Delivery failures never switch back to weaker authentication.

Native blog posts

Articles arrive as standard blog.post records. Delivered media can be stored locally, authors use connector-owned identities, and native tags reuse exact labels without renaming shared customer tags.

SEO + GEO optimized

Every article is optimized not just for Google but also for AI search engines like ChatGPT, Perplexity, and Claude. Schema.org markup, meta descriptions, and structured headings come built-in.

Dutch-first pilot

The first pilot is Dutch. Additional languages and customer routing need representative native validation before a multilingual rollout is claimed.

Works with Odoo SEO

Built on top of Odoo's native website_blog module, so canonical URLs, sitemap.xml, breadcrumbs and Open Graph tags all keep working exactly as Odoo designed them. Article JSON-LD is added only when no Article/BlogPosting owner already exists. Customer robots and noindex policy remain authoritative.

How it works

1. Install the module

Install Launchmind Blog from the Odoo Apps store. It depends only on the standard website_blog module. Hosting must allow custom Python addons; standard Odoo Online without custom addons is not supported.

2. Connect your account

Go to Settings > Website > Launchmind Blog, paste your API key (find it at launchmind.io > Dashboard > Settings > API), and click Connect after selecting the website and blog.

3. Confirm and verify

Wait for signed confirmation, inspect diagnostics, and verify an approved staging article. Customer publication, canary and backlog activation need separate approval.

4. Configure optional features

Telemetry is opt-in and needs customer approval. It includes full referrer and clicked-target URLs, origin-observed crawler data and daily health. IndexNow stays disabled until production-domain proof and separate activation approval.
